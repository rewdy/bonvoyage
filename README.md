# 👋 Bon Voyage

Set up your custom scss projects quickly. This takes care of CSS vars, light/dark mode, and semantic elements. It gives a sensible starting point for building your next project.

If you *actually know* CSS and don't like Tailwind, this is for you. 😉

## To Use

Run this and answer the questions:

```bash
bunx @rewdy/bonvoyage bonvoyage
```

Don't bother doing this, but you can also install globally and use `bonvoyage` or `bon-voyage` locally:

```bash
npm i -g @rewdy/bonvoyage

# Then from your project directory

bonvoyage
```

🥟 This project was created using `bun init` in bun v1.3.6. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
